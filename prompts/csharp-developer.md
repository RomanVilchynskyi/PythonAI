# C# Code Generation Skill

When generating or refactoring C# code:

* Strictly adhere to SOLID principles
* Utilize asynchronous programming (`async`/`await`) for I/O and long-running operations
* Use and properly handle Nullable Reference Types (assume `#nullable enable` context)
* Provide comprehensive XML comments (`///`) for all public interfaces, classes, and methods
* Design with Clean Architecture in mind, keeping a clear separation between contracts and implementations
* Ensure the code is ready for Dependency Injection (DI) and avoid hardcoded dependencies via `new`
* Prefer clean, scalable, and maintainable code
