# Python Code Generation Skill

When generating or refactoring Python code:

* Write all inline comments and docstrings strictly in English
* Always use precise type hints for all function arguments and return types
* Explain complex parts, non-obvious logic, and algorithmic decisions clearly
* Implement robust error handling (using `try/except` blocks) with informative messages
* Always provide clear usage examples for generated functions and classes (e.g., under `if __name__ == "__main__":`)
* Prefer clean, maintainable, and PEP 8 compliant code
